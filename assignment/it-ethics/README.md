# จริยธรรมและจรรยาบรรณในการใช้เทคโนโลยีสารสนเทศ

ชุดสื่อสำหรับอัดคลิปส่งครู หัวข้อ **จริยธรรมและจรรยาบรรณในการใช้เทคโนโลยีสารสนเทศ + ข่าว 1 เรื่อง**

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | สไลด์ 12 หน้า เปิดในเบราว์เซอร์แล้วแชร์หน้าจอ |
| `script.md` | สคริปต์พูดประมาณ 3.30–4.30 นาที |
| `fonts/` | ฟอนต์ไทย เปิดออฟไลน์ได้ |

## วิธีอัดคลิป

1. เปิด `index.html` ด้วย Chrome หรือ Edge
2. กด `F11` ให้เต็มจอ
3. เปิดกล้อง + ไมค์ แล้วแชร์หน้าจอสไลด์
4. อ่านตาม `script.md` ค่อย ๆ พลิกสไลด์ด้วยลูกศรขวา หรือคลิก
5. อยากให้สไลด์วิ่งเอง ให้กด `A` หรือเปิด `index.html?autoplay=1`

ข่าวที่ใช้วิเคราะห์คือข่าวจริงของกระทรวงดีอี / AOC 1441 วันที่ 9 กุมภาพันธ์ 2569 เรื่องมิจฉาชีพใช้ AI Deepfake และ Voice Clone ปลอมเสียงคนในครอบครัวเพื่อหลอกโอนเงิน

## คลิปตัวอย่าง

มีคลิปนำเสนอพร้อมเสียงบรรยายภาษาไทย ความยาวประมาณ 4 นาที 48 วินาที ให้เปิดดูเพื่อท่องและซ้อมก่อนอัดด้วยเสียงตนเอง

ถ้าครูกำหนดว่าต้องเห็นหน้าและได้ยินเสียงนักเรียน ให้เปิด `index.html` แล้วอ่านตาม `script.md` เอง อย่าส่งคลิปตัวอย่างแทนเสียงของตนเอง
